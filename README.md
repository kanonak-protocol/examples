# examples
Public examples of different use cases for Kanonak Protocol

| Example | What it shows |
|---|---|
| [versioned-rule-bases](versioned-rule-bases/) | Bodies of rules shipped as versioned packages: French prescription law across two editions and the FIDE Laws of Chess, each rule pinned to the source text it models, with an evaluator that answers dated questions. |
| [manufacturing-assembly](manufacturing-assembly/) | A tutorial that takes someone new to ontologies to their own assembly process as a validated model, built with Claude Code and the Kanonak skill: a schema of processes, steps, tools and components, a sample wheel build, and a look that serves them as linked pages on localhost. |
